## 1. 브랜드 아이덴티티 정의

| 항목 | 내용 |
| --- | --- |
| **브랜드명** | **NOVA Core** (가상 브랜드) |
| **제품** | NOVA Core One — 초소형 AI 미니 PC |
| **타겟** | 25~40세 크리에이터, 개발자, 재택근무 직장인 (공간 효율 + 고성능을 동시에 원하는 사용자) |
| **톤앤매너** | 미니멀 · 미래지향 · 신뢰감 — 차분한 내레이션 + 세련된 다크 톤 영상미 |
| **USP (차별점)** | "손바닥 위의 AI 워크스테이션" — 초소형 폼팩터(8cm³)에 온디바이스 AI 엔진 내장, 로컬 LLM 구동 가능 |
| **브랜드 슬로건** | **"Small Body. Massive Mind."** |

## 3. 사용 도구 목록 및 선정 이유

| 카테고리 | 도구 | 선정 이유 |
| --- | --- | --- |
| **이미지 생성** | MoneyPrinterTurbo (MCP) | 다양한 AI를 무료로 써서 스토리보드의 이미지를 생성하기에 품질이 가장 우수 |
| **비디오 생성** | **Runway Gen-3 Alpha** | 이미지→비디오 변환(Image-to-Video) 기능이 안정적이며 카메라 모션 제어가 가능 |
| **오디오 생성 (BGM)** | **Suno AI v4** | 장르·분위기 키워드만으로 고품질 배경음악을 빠르게 생성, 상업적 사용 라이선스 제공 |
| **오디오 생성 (내레이션)** | **ElevenLabs** | 자연스러운 한국어/영어 TTS, 톤·속도 세밀 조절 가능 |
| **편집/합성** | **CapCut (데스크톱)** | 무료이면서 자막·트랜지션·오디오 믹싱을 한 곳에서 처리 가능 |
