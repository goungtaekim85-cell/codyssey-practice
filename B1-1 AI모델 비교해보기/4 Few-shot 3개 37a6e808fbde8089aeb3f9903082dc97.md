## 예시 1: 좋은 입력 → 좋은 출력 (협업 제안)

### *입력:**

[목적] 외부 디자인 에이전시에 브랜드 리뉴얼 협업 제안

[수신자] 에이전시 대표

[핵심 포인트] 프로젝트 개요, 8~10월 일정, 미팅 요청

[톤] 정중하고 전문적

[금지] 구체적 예산 언급

[분량] 300자

### *출력:**

제목: 브랜드 리뉴얼 프로젝트 협업 제안 건

담당자님께,

안녕하세요. ○○ 마케팅팀입니다.

현재 저희는 브랜드 리뉴얼 프로젝트를 기획 중이며,

귀사의 전문성을 바탕으로 협업을 제안드리고자 합니다.

- 프로젝트: 브랜드 아이덴티티 리뉴얼 (로고, 가이드라인)
- 예상 일정: 2025년 8월~10월 (약 3개월)

세부 사항 논의를 위해 미팅을 요청드립니다.

편하신 일정을 회신해 주시면 감사하겠습니다.

감사합니다.

## 예시 2: 좋은 입력 → 좋은 출력 (일정 변경)

### *입력:**

[목적] 기존 미팅 일정 변경 요청

[수신자] 내부 개발팀 리드

[핵심 포인트] 기존 7/10 → 7/14로 변경, 사유: 외부 미팅 겹침

[톤] 친근하되 예의 바르게

[금지] 없음

[분량] 150자

### *출력:**

제목: 7/10 미팅 일정 변경 요청드립니다

○○님, 안녕하세요!

7월 10일 예정된 미팅과 관련하여, 같은 시간에 외부 미팅이

잡혀 부득이하게 일정 변경을 요청드립니다.

- 변경 요청: 7/10(목) → 7/14(월) 같은 시간

혹시 해당 일정이 어려우시면 말씀해 주세요.

불편을 드려 죄송합니다!

감사합니다.

## 예시 3: 모호한 입력 → AI가 되묻는 케이스 ⭐

### *입력:**

거래처에 메일 하나 써줘. 좀 급한 건이야.

### *출력:**

메일을 작성하기 전에 몇 가지 확인이 필요합니다:

1. **메일의 목적**이 무엇인가요?

(예: 납기 독촉, 계약 변경 요청, 클레임 등)

2. **수신자**는 어떤 직급/관계인가요?

(예: 거래처 담당자, 대표 등)

3. **핵심적으로 전달할 내용**은 무엇인가요?

위 정보를 알려주시면 상황에 맞는 메일을 바로 작성해 드리겠습니다.
